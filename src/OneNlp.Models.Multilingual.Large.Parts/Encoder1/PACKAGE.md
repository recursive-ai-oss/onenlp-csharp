# Encoder1

Part of the base-size accurate-tier model of OneNLP (spaCy-class NLP for .NET): layers 1 of 2 (the first half of the bytes of the fine-tuned encoder layers). Reference `RecursiveAI.OneNlp.Models.Multilingual.Large`, which depends on this package; it is split only to keep each package under the size limit of nuget.org. Unaffiliated with other projects named OneNLP.
